# Ses fontları (SoundFont / SF2)

7. aşama (enstrüman ve ses üretimi) bu dizindeki SF2 dosyalarını kullanır.
Telif nedeniyle dosyalar depoya eklenmez (bkz. `.gitignore`).

Önerilen ücretsiz, ticari kullanıma uygun fontlar:

- **GeneralUser GS** — geniş enstrüman yelpazesi, ticari kullanıma izinli
- **FluidR3 GM/GS** — MIT benzeri lisans
- **MuseScore_General** — MIT lisanslı

Dosyayı `assets/soundfonts/*.sf2` olarak kopyalayın; `python scripts/check_env.py`
otomatik olarak algılar.
